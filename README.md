# API Escape Room Workshop

An interactive workshop that combines API development with an engaging, game-like learning experience. Students learn API basics and Bruno API client usage through solving puzzles in an "escape room" format.

## Workshop Overview

This workshop teaches college students about:
- **REST API Basics**: Understanding how APIs work from server and client perspectives
- **Bruno API Client**: Practical use of Bruno for API testing and exploration
- **API Client Components**: Request methods, headers, body types, environment variables
- **File System Based Approach**: How Bruno stores collections in filesystem
- **Git Integration**: Collaborative API development using version control

## Technology Stack

- **Backend**: FastAPI (Python) - Modern, fast, with automatic API documentation
- **API Client**: Bruno - Open source, file-based API client
- **Frontend**: Simple HTML/CSS/JS for game visualization
- **Version Control**: Git for collaborative API collection management

## Workshop Structure

### Module 1: REST API Basics
Learn the fundamentals of REST APIs through hands-on examples.

### Module 2: Bruno API Client
Introduction to Bruno and its core features.

### Module 3: API Client Components
Deep dive into request methods, headers, body types, and environment variables.

### Module 4: File System Based Approach
Understanding how Bruno stores collections as files and folders.

### Module 5: Git Integrated API Client
Collaborative API development using Git with Bruno collections.

### Module 6: Escape Room Challenge
Interactive puzzle-solving using all learned concepts.

## Getting Started

1. Clone this repository
2. Install Python dependencies: `pip install -r requirements.txt`
3. Run the FastAPI server: `python main.py`
4. Download Bruno from [usebruno.com](https://www.usebruno.com/)
5. Open Bruno and import the workshop collections

## Workshop Collections

The workshop includes Bruno collections for each module:
- `collections/module1-rest-basics/`
- `collections/module2-bruno-client/`
- `collections/module3-api-components/`
- `collections/module4-filesystem/`
- `collections/module5-git-integration/`
- `collections/module6-escape-room/`

## Learning Objectives

By the end of this workshop, students will:
- Understand REST API fundamentals
- Be proficient with Bruno API client
- Know how to structure API requests and responses
- Understand file-based API collection management
- Be able to collaborate on API collections using Git
- Have hands-on experience with real API development scenarios
