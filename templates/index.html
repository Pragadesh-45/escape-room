Workshop Overview

This interactive workshop combines API development with an engaging, game-like learning experience. You'll learn REST API basics and Bruno API client usage through solving puzzles in an "escape room" format.

Module 1: REST API Basics

Learn the fundamentals of REST APIs through hands-on examples

  • HTTP Methods (GET, POST, PUT, DELETE)
  • Request/Response patterns
  • Status codes and error handling

Module 2: Bruno API Client

Introduction to Bruno and its core features

  • Bruno interface overview
  • Creating and organizing requests
  • Environment management
Start Module 2

Module 3: API Client Components

Deep dive into request methods, headers, body types, and environment variables

  • Request methods and when to use them
  • Headers and authentication
  • Request body formats
Start Module 3

Module 4: File System Based Approach

Understanding how Bruno stores collections as files and folders

  • Collection structure
  • File-based storage
  • Organization best practices
Start Module 4

Module 5: Git Integrated API Client

Collaborative API development using Git with Bruno collections

  • Version control for API collections
  • Team collaboration
  • Collection sharing
Start Module 5
