Authentication Flow

  1. Login: Send credentials to get a token
  2. Token Storage: Save the token in environment variables
  3. Authorization: Use token in headers for protected endpoints

Key Concepts

🔐 Authentication Types

  • Basic Auth: Username/password
  • Bearer Token: Token-based auth
  • API Key: Simple key authentication

📋 Header Management

  • Content-Type: application/json
  • Authorization: Bearer token
  • Custom Headers: X-API-Key, etc.

📝 Body Formats

  • JSON: Structured data
  • Form Data: Key-value pairs
  • Raw: Plain text
