Module 1: REST API Basics

Learn the fundamentals of REST APIs through hands-on examples

What You'll Learn

  • HTTP Methods (GET, POST, PUT, DELETE)
  • Request/Response patterns
  • Status codes and error handling
  • Path parameters and request bodies

Getting Started

  1. Open Bruno and import the "Module 1: REST API Basics" collection
  2. Make sure the FastAPI server is running on http://localhost:8000
  3. Start with the "Hello World" request

Bruno Collection Structure

collections/module1-rest-basics/ ├── bruno.json ├── environments/ │ └── local.bru └── requests/ ├── 01-hello-world.bru ├── 02-get-user.bru ├── 03-create-user.bru ├── 04-update-user.bru └── 05-delete-user.bru

Request Examples

1. Hello World - Basic GET Request

GET {{baseUrl}}/api/module1/hello

Your first API call! Learn the basic request/response pattern.

2. Get User by ID - Path Parameters

GET {{baseUrl}}/api/module1/user/{user_id}

Learn how to use path parameters in URLs. Try different user IDs: 1, 2, 3, 999.

3. Create User - POST Request

POST {{baseUrl}}/api/module1/users

Learn how to send data to create new resources. Modify the JSON body with your information.

4. Update User - PUT Request

PUT {{baseUrl}}/api/module1/users/{user_id}

Learn how to update existing resources. Try updating different users.

5. Delete User - DELETE Request

DELETE {{baseUrl}}/api/module1/users/{user_id}

Learn how to remove resources. Understand the CRUD operations.

Key Concepts

HTTP Methods

  • GET: Retrieve data
  • POST: Create new resources
  • PUT: Update existing resources
  • DELETE: Remove resources

Status Codes

  • 200: Success
  • 201: Created
  • 400: Bad Request
  • 404: Not Found

Data Formats

  • JSON: JavaScript Object Notation
  • Path Parameters: Values in URL
  • Request Body: Data sent to server

Exercises

  1. Send the Hello World request and observe the response
  2. Try getting users with IDs 1, 2, 3, and 999. What happens?
  3. Create a user with your name and favorite programming language
  4. Update user ID 2 with new information
  5. Try deleting a user and observe the response
