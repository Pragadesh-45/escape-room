Bruno Interface Overview

📁 Collection Panel (Left)

  • Organize requests in folders
  • Environment variables
  • Collection settings

📝 Request Panel (Center)

  • HTTP method selection
  • URL input field
  • Headers management
  • Request body editor

📊 Response Panel (Right)

  • Status code display
  • Response body (JSON/formatted)
  • Response headers
  • Request timing

Request Examples

1. Check API Status

GET {{baseUrl}}/api/module2/status

Learn Bruno's interface components and how to send requests.

2. Headers Demonstration

GET {{baseUrl}}/api/module2/headers

Understand how Bruno handles HTTP headers and how servers read them.

3. Echo Request

POST {{baseUrl}}/api/module2/echo

See how Bruno sends complete request information including body and headers.

Environment Variables

Bruno uses environment variables to make requests reusable and maintainable:

vars { baseUrl: http://localhost:8000 apiVersion: v1 }

Use variables in requests with {{variableName}} syntax.

Key Bruno Features

🎯 Environment Management

Switch between different environments (local, staging, production) easily.

📁 File-Based Collections

Collections are stored as files, making them version-controllable with Git.

🔍 Request History

Bruno keeps track of your request history for easy reference.

📝 Documentation

Add documentation directly to your requests using Markdown.
